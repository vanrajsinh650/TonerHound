**Date**: October 1, 2026  
**Status**: Completed  
**Source Dataset**: `research/observer/field_records.parquet`

## 1. Executive Summary

This audit confirms the existence, schema, and volume of field-level and candidate-level training data within the Observer V2 dataset (`field_records.parquet`). The dataset provides complete end-to-end trace logs across 236 documents and 445,950 total gradeable field records. Both Development Cohort A (32 documents) and Held-Out Cohort B (32 documents) are 100% represented with comprehensive candidate pools, spatial locations, and ground-truth citations.

The audit confirms **abundant candidate-level training data**:
- **Cohort A (Development)**: 176,112 fields total; **89,154 multi-candidate fields** containing **602,394 candidate records**, with **51,084 positive candidates** ($\text{IoU} \ge 0.50$).
- **Cohort B (Held-Out)**: 178,930 fields total; **71,439 multi-candidate fields** containing **~480,000 candidate records**.
- On multi-candidate fields, existing production selection Hit@1 is only **20.03%** on Cohort A and **25.00%** on Cohort B, while pool recall ($\text{IoU} \ge 0.50$) is **71.13%** and **75.83%** respectively. This confirms a **~50.8pp candidate selection gap** amenable to reranking.

## 3. Candidate & Gold Representation Details

### A. Candidate Pool Schema (`candidate_pool`)
Candidates are serialized as a JSON string containing an ordered array of candidate objects:
```json
[
  {
    "rank": 1,
    "source": "exact",
    "text": "BlackRock HPS Credit Strategies Fund",
    "normalized_text": "blackrock hps credit strategies fund",
    "page": 46,
    "bbox": [0.050394, 0.294498, 0.191080, 0.011675],
    "iou_by_gold": [0.0],
    "best_iou": 0.0,
    "best_gold_index": 0
  },
  {
    "rank": 2,
    "source": "exact",
    "text": "BlackRock HPS Credit Strategies Fund",
    "normalized_text": "blackrock hps credit strategies fund",
    "page": 38,
    "bbox": [0.646857, 0.249794, 0.209695, 0.010871],
    "iou_by_gold": [0.0],
    "best_iou": 0.0,
    "best_gold_index": 0
  }
]
```
Candidate attributes present:
1. `rank`: 1-indexed baseline priority rank.
2. `source`: Match tier channel (`exact`, `normalized_number`, `normalized_date`, `boolean`, `fuzzy`, `recovered_fragmented_numeric`, `recovered_interleaved`, `recovered_spaced_numeric`, `recovered_split_symbol`).
3. `text`: Raw sighted token/span text.
4. `normalized_text`: NFKC-normalized, lowercase token text.
5. `page`: 1-indexed document page number.
6. `bbox`: Normalized coordinates $[x, y, w, h] \in [0, 1]^4$.
7. `best_iou`: Evaluation IoU against closest gold box (used strictly for training label generation: $y = \mathbb{I}(\text{best\_iou} \ge 0.50)$).

### B. Gold Citation Representation
Gold evidence is defined per field in:
- `gold_value`: Exact string target (query).
- `gold_evidence_entries`: Normalized boxes and page indices, e.g.:
  `[{"page": 8, "bbox": [0.65918, 0.023, 0.31051, 0.01292]}]`.
- `gold_pages`: Ground-truth page(s).

### Confirmation of Data Sufficiency
There is **more than sufficient candidate-level data** for training:
- With 89,154 multi-candidate fields and 602,394 candidates in Cohort A, statistical power is extraordinarily high.
- The 51,084 positive instances provide rich representation across all match channels (exact, numeric, fuzzy, recovery, table/form contexts).
- Strict separation between Cohort A (training only) and Cohort B (held-out evaluation only) is fully verified.
- No production code was modified during this audit.
